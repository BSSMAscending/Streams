# Streams

TeamAscending의 카드 배치 게임입니다.

## 플레이하기

브라우저에서 바로 할 수 있습니다.

**[브라우저에서 플레이](https://bssmascending.github.io/Streams/)**

브라우저에서는 계산이 오래 걸리기에, AI의 계산 횟수를 줄여 두었습니다. 원본 AI와 두고 싶다면 아래 파일을 받아 실행하세요.

Windows용 실행 파일도 받을 수 있습니다.

**[최신 버전 다운로드](https://github.com/BSSMAscending/Streams/releases/latest)**

1. 위 링크에서 `Streams.zip`을 받습니다.
2. 압축을 풉니다.
3. `Streams.exe`를 실행합니다.

Windows에서 경고가 뜨면 **추가 정보 → 실행**을 누르면 됩니다.
